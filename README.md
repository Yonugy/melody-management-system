# Introduction

## Background
With the development of today's technology, more IoT-based devices are being developed for creative and educational purposes. They are more interactive and accessible than traditional musical instruments, but at the same time they have more capabilities than ordinary electronic keyboards. Most modern digital instruments focus primarily on advanced features like Musical Instrument Digital Interface (MIDI) connectivity and professional sound synthesis while the user is performing (Ine, 2025). The instruments themselves often include multiple input methods such as piano keys, drum pads, and control knobs. But the instruments themselves are typically expensive and complex, making them less accessible to beginners and hobbyists who want to learn music composition.
<br>
As more people are interested in learning music and creating their own compositions, educational tools have become increasingly important. Cases of expensive musical instruments sitting unused have become more common because they are too complex for beginners. Compared to ordinary electronic keyboards, it is much easier for IoT-based instruments to provide interactive learning experiences. There are several reasons for this, such as the fact that they use cloud connectivity for storing compositions and they have integrated metronomes for practice. They have a higher level of accessibility than professional MIDI controllers. But just like a normal keyboard, traditional instruments are unable to automatically save the user's compositions or provide remote access to their musical ideas when they are away from the instrument.
<br>
At the same time the issue of music education and creative expression has now become a vital concern for learners and educators, most of whom invest in expensive lessons and instruments, but wouldn't it be better to provide an affordable and interactive platform for learning rather than relying solely on traditional methods? Thus, to address these possibilities, I have developed an IoT based touch piano system to provide a real-time platform for music composition with cloud storage and remote access capabilities.

## Objectives
The main objective of the project is to enable users to create, record, and manage musical compositions in real time using an accessible touch-based interface. The connection is made using IoT technology and cloud storage through Firebase. The main aim is to help enhance music learning, reduce barriers to music creation, and provide peace of mind for users to know their compositions are safely stored in the cloud.

## System Scope
The current scope of the system is to detect touch inputs and generate musical sounds across twelve keys covering a full octave. The system itself includes the integration of several components, such as the twelve capacitive touch sensors, which I use to detect finger contact on each piano key, and the twelve passive buzzers, which are used to generate sound at specific frequencies corresponding to musical notes. The TM1637 4-digit display is used to show the current BPM setting for the metronome. The rotation angle sensor allow users to adjust the metronome speed from 40 to 200 BPM by rotating it, and the system updates the display in real time. The mode selection button enables users to cycle through three modes including start recording, stop recording, and play latest melody. Finally, the metronome toggle button is designed to turn the practice metronome on or off, while the dedicated metronome buzzer provides audio feedback separate from the piano keys.

## Function
The twelve capacitive touch sensors can be used as real-time input devices to detect when a user touches any of the twelve piano keys from C to B, triggering the corresponding buzzer to play the appropriate musical note. The TM1637 display shows the current BPM setting and updates dynamically as the user adjusts the rotation angle sensor. And the mode selection button is designed to allow users to start recording their melody, stop the recording and save it, or play back their most recently recorded composition with a simple press. And the purpose of the metronome toggle button is to help users practice with a steady beat by enabling or disabling the metronome tick sound. The purpose of using dual ESP32 microcontrollers is to distribute the processing load, where the Master ESP32 handles WiFi connectivity, web server hosting, Firebase integration, and seven upper keys, while the Slave ESP32 manages five lower keys and the metronome buzzer through I2C communication protocol.
<br>
By integrating these functions, my touch piano system can provide users with an intuitive platform for music creation, recording melodies with millisecond-precision timing, uploading compositions to Firebase cloud storage with timestamps and metadata, and accessing their melody library through a responsive web interface from any device with internet connection. Subsequently, it also allows the user to play back melodies either on the physical piano or through the browser with visual feedback on an animated keyboard, edit melody names, delete unwanted recordings, and practice with a variable-speed metronome, ensuring their musical ideas are preserved and accessible anytime, anywhere.
